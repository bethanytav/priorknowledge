# Prior Knowledge Project:
This repository exists for the purpose of allowing individuals to reproduce results from the publication "Prior and current experiences impact perceived effort when learning new skills". Data are fully de-identified.

# General Information:
- main goal: investigate the relationship of how prior knowledge impacts skill learning
- this data was collected in UCR undergraduate students
- the task involved learning statistical software (SPSS, Jamovi, R)

# 3 Main Variables:
  1) prior knowledge (people who had prior non-statistics coding experience vs. none)
  2) task order (completing easy-task-first: Jamovi -> R vs. completing hard-task-first: R -> Jamovi)
  3) main outcome: time taken on each of the three tasks (TOT)
other outcomes include measures of motivation and perceived effort
